# README
As Lovelace written, mathematics is divided into two parts, mechanical and reasoning. And we let the machine to do the mechanical part and we do the reasoning by pure intellect.

Far beyond from Pascal's Machine, we can perform omplicated computation using computer, other than arithmetic operations. However, the Pascal's Machine cannot preserve accuracy and time efficiency, this is not a problem for noewadays' Computer.
